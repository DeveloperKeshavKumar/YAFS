# example3

A YAFS application.

## Getting Started

### Development

```bash
# Start development server
php server.php

# Visit
http://localhost:8000
```

### Documentation

- Routes: Edit `routes/web.php`
- Views: Edit files in `views/`
- Assets: Place in `public/assets/`

### Add React

```bash
php yafs add react
```

### Production

```bash
# Build assets (if using React)
cd frontend && npm run build

# Deploy to server
# Set public/ as document root
```
